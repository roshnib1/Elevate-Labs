# 📊 Financial Dashboard – Power BI  
## 🚀 Task 4: Dashboard Design for Business Stakeholders  

### 📌 Project Overview  
An interactive financial dashboard created using Power BI to help stakeholders analyze key business metrics. It includes total sales, profit margin, profit trends, discount insights, and product-level performance.

---

### 🎯 Objectives  
- Track KPIs: Total Sales, Profit, COGS, Average Profit per Order  
- Enable dynamic filtering and drill-downs  
- Support strategic decisions with clean, visual insights  
- Present sales by geography, segment, product, and discount bands  

---

### 🧠 Insights & Visuals  
| Visual                      | Insight Provided                              |
|----------------------------|-----------------------------------------------|
| **KPI Cards**              | Sales, Profit, Profit Margin, COGS, Avg Profit |
| **Map Chart**              | Total Sales by Country and Segment             |
| **Donut Chart**            | Sales by Discount Band                         |
| **Line Chart**             | Sales trend across segments                    |
| **Bar Chart**              | Sales by Product (Top contributors)            |
| **Slicers**                | Filter by Country, Segment, Product, Time etc. |
