# Sales Transaction Analysis

## Overview

This project uses **SQLite**, **Python**, and **SQL queries** to analyze a dataset of sales transactions. It calculates key insights, such as total sales quantity and revenue for each product. The results are visualized using a **bar chart**. The project is designed to run in **VS Code** and provides an excellent opportunity to practice SQL queries and basic data analysis.

---

## Project Setup and Execution

### Prerequisites

To run this project, ensure that the following are installed:

1. **Visual Studio Code**:  
   Install [VS Code](https://code.visualstudio.com/).
   
2. **Python 3.x**:  
   Install Python from [python.org](https://www.python.org/downloads/).

3. **Python Libraries**:  
   You will need the following libraries:
   - `sqlite3` (built-in with Python)
   - `pandas`
   - `matplotlib`
   
   To install `pandas` and `matplotlib`, run:
   ```bash
   pip install pandas matplotlib
